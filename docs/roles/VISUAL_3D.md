## 4. 3D 实现建议

### 4.1 技术方案

- Three.js（裸用，不引入 `@react-three/fiber` / `@react-three/drei`）；
- 自定义 `ShaderMaterial` 实现能量球体；
- 顶点位移使用 3D 噪声/fbm，形成流动表面；
- 片元着色器组合：
  - 深蓝/紫色基础色；
  - Fresnel 边缘光；
  - 流动光带；
  - 细碎星尘/噪点；
  - 适度的色相变化；
- 外围粒子层和细轨道环；
- 不使用巨大 HDR 环境贴图；
- 后处理 bloom 按性能决定，优先使用自定义加法辉光。

### 4.2 组件建议

```text
src/components/three/
├─ energy-core-canvas.tsx      # 客户端 Canvas 包装、动态加载
├─ energy-core-scene.tsx       # 场景组织
├─ core-sphere.tsx             # 球体与 shader
├─ particle-field.tsx          # 粒子
├─ orbital-rings.tsx           # 轨道环
├─ energy-core-fallback.tsx    # CSS/SVG 回退
└─ shaders/
   ├─ core.vert
   └─ core.frag
```

### 4.3 性能预算

- DPR 上限约 1.5–1.75；
- 桌面粒子建议 1500–3000，移动端 600–1200，具体按实测调整；
- 避免每帧创建对象；
- 指针交互用 refs，不触发 React 状态更新；
- 页面隐藏或 Canvas 离开视口时暂停渲染；
- 只创建一个 WebGL Canvas；
- 路由切换时释放几何体、材质、纹理和事件；
- 目标：桌面 60fps 体感，移动端不明显掉帧；以实际设备测试为准。

### 4.4 视觉集成

- Canvas 作为背景/视觉层，通过 `pointer-events` 控制不遮挡输入框和按钮；
- 首屏先显示 CSS 静态核心轮廓，3D 加载完成后淡入；
- 核心与标题、网格、星尘背景共享色调和光源方向；
- 移动端缩小核心、降低粒子数量，不把核心放在文字下方造成可读性问题；
- 深色背景上保持文字对比度。

## 5. 验收标准

- 首页第一眼有明确视觉焦点和品牌识别度；
- 3D 是真实实时渲染，不是静态图片；
- 3D 不阻塞输入、滚动和导航；
- 鼠标移动有克制视差，交互有自然反馈；
- 中英文布局都不溢出、不错位；
- 360px、390px、768px、1024px、1440px 下可用；
- `prefers-reduced-motion` 下关闭或弱化自动动画；
- WebGL 不可用时显示同色调回退；
- 无控制台错误、无明显内存泄漏；
- 不复制其他产品的品牌资产或页面。
