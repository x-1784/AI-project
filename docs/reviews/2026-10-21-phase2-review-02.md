## 4. 发现

### 4.1 可访问性

**P2 回退 SVG 的无障碍标签被父级 `aria-hidden` 覆盖**

- 位置：`energy-core-stage.tsx:148-155`
- 事实：外层 `<div ... aria-hidden="true">` 包住 `<EnergyCoreFallback label={fallbackLabel} />`，而后者渲染 `<svg role="img" aria-label={label}>`
- 影响：`aria-hidden` 作用于整个子树，`role="img"` 与 `aria-label` **全部失效**。`Home.core.fallbackLabel`（中英都已翻译）实际不会被任何读屏读到
- 与文档的冲突：`PHASE2_SUMMARY.md §3.4` 声称「回退 SVG 带 `能量核心静态预览` 标签」，该断言在可访问性树上不成立
- 建议：二选一 ——
  1. 若 3D 核心属装饰：保留 `aria-hidden`，删除 `fallbackLabel` prop 与 `Home.core.fallbackLabel`；
  2. 若需播报：去掉外层 `aria-hidden`（canvas 那一侧已自带 `aria-hidden="true"`，不会重复）

**P3 `Home.core.ariaLabel` 是死 key**

- 双语均定义（`NEBULA 能量核心` / `NEBULA energy core`），`src/**` 中引用次数为 **0**

### 4.2 性能

**P2 核心几何体为非索引结构，顶点着色器多跑约 5 倍**

- 位置：`energy-core-canvas.tsx:286`（`coreGeo`）、`:295`（`shellGeo`）
- 事实：`IcosahedronGeometry` 生成非索引几何体，球面上本可共享的顶点被展开成独立顶点。实测 `full` 档 50,460 顶点 vs 合并后 8,499
- 影响：`full` 档单帧 45.4 万次 `snoise`，其中约 83% 是重复计算的同一球面位置
- 安全性：顶点着色器用 `normalize(position)` 取方向，法线由有限差分在 shader 内重算、**不依赖几何体法线**，因此合并顶点不产生视觉差异
- 建议：`mergeVertices(rawGeo, 1e-4)`（来自 `three/examples/jsm/utils/BufferGeometryUtils.js`），或退一步把 `detail` 从 28 降到 20（8,820 三角形 / 26,460 顶点，视觉差异极小）
- 注：`PHASE2_SUMMARY.md §5` 已登记「`compact` 档真机帧率未测」，本条给出了具体可调的杠杆

**P2 3D chunk 在水合后立即开始下载**

- 事实：132.7 KB gzip 的 scene chunk 在 `useSyncExternalStore` 返回非 `pending` 档位时挂载，即首屏水合后立即触发
- 影响：占用首屏带宽与主线程解析时间，间接影响 INP
- 建议：可延后到 `requestIdleCallback` 再挂载（已有 SVG 占位，延迟不影响观感），或在 `next.config` 里对该 chunk 加 `prefetch: false`。当前有 fallback 兜底，不构成缺陷

### 4.3 可维护性

**P2 `Button` 样式被手工复制到 `closing-cta`**

- 位置：`closing-cta.tsx:22-27`
- 事实：注释自述「样式按 Button primary / lg 的类逐一照抄」，因为 `Button` 渲染 `<button>`，用按钮做页内跳转会丢掉原生锚点能力
- 影响：样式的单一来源被破坏。这是第一批 P1-3（`cn()` 不能可靠覆盖冲突类）的下游后果 —— 因为无法用 `<Button className>` 覆盖，只能整串复制
- 建议：给 `Button` 增加 `asChild`（Slot 模式），`closing-cta` 改为 `<Button asChild size="lg">`。这与 P1-3 一并解决收益最大

**P3 `hero-composer` 使用 `max-w-[min(560px,72vw)]`**

- 全仓库其余容器已统一 `max-w-7xl`，此处是唯一自定义宽度。语义不同（输入框最大宽度），可接受，记录备查

### 4.4 文档一致性

**P3 验收记录的 Node 版本号会过期**

- `PHASE2_SUMMARY.md §3.1` 写 `Node v24.18.0`；实际本地为 `v24.20.0`，CI 使用 `node-version: 24`（浮动到最新 24.x）
- 建议：写成「24.x（CI 实测版本）」而非精确补丁号

## 5. 确认无问题的项

以下为逐项核对后**确认成立**的部分，不列为发现：

### 5.1 3D 资源生命周期（检查清单 §3.4 首次有实物可查）

| 检查点 | 结论 |
| --- | --- |
| `BufferGeometry.dispose()` | `coreGeo` / `shellGeo` / `glowGeo` / `particleGeo` / 每个 `ringGeo` 全部释放 |
| `Material.dispose()` | `coreMat` / `shellMat` / `glowMat` / `particleMat` / 每个 `ringMat` 全部释放 |
| 纹理 | 无纹理，纯 Shader 生成，无泄漏面 |
| `WebGLRenderer.dispose()` | 已调用 |
| WebGL context | 额外调用 `forceContextLoss()`，注释解释了档位切换时 context 堆积撞上限的风险 |
| `requestAnimationFrame` | `cancelAnimationFrame(raf)` 在卸载时取消 |
| 事件监听 | `pointermove` / `visibilitychange` 均已 `removeEventListener` |
| 观察者 | `ResizeObserver` / `IntersectionObserver` 均已 `disconnect()` |
| DOM 节点 | `renderer.domElement.remove()` |

**这是本阶段做得最扎实的一块**，明显超出一般实现的平均水平。

### 5.2 性能设计

- 双暂停条件：标签页隐藏 **或** 滚出视口，任一满足即 `cancelAnimationFrame`
- 后台标签页中打开时 `start()` 直接返回，不再空转排队 rAF
- 恢复时重置 `last`，避免暂停期间累积时间导致首帧跳变
- 静态档（`reduced`）不跑循环，`resize` 后补一帧，避免画布空白
- `setSize(w, h, false)` 只改 backing store、不写 DOM style，注释解释了 `<canvas>` 替换元素的固有尺寸陷阱
- DPR 上限分档：`full` 1.5 / `compact` 1.25 / `reduced` 1.0
- `interactive=false` 仅与 `reduced` 同现，此时 `animate` 也为 `false`，**不存在「每帧渲染静止画面」的浪费**（已专门核对参数组合）

### 5.3 客户端 / 服务端边界

- 客户端组件仅 3 个：`hero-composer`（需要表单状态）、`energy-core-canvas`（WebGL）、`energy-core-stage`（`useSyncExternalStore`）
- 5 个首页区块、`hero`、`layout` 均为 Server Component
- `three` 只被 `energy-core-canvas` 引用，且经 `dynamic(ssr: false)` 隔离
- `useSyncExternalStore` 的 `subscribe` / `getSnapshot` 引用同一批懒初始化的 `MediaQueryList`，未出现「监听挂一处、读取在另一处」的经典错误
- `getServerSnapshot` 固定返回 `pending`，水合不产生不匹配

### 5.4 输入与安全

- `src/**` 无 `dangerouslySetInnerHTML` / `innerHTML` / `eval` / `new Function`
- 无网络请求、无密钥读取、无环境变量进入客户端
- `HeroComposer` 的 `onSubmit` 仅 `preventDefault()`，未伪造提交结果，符合「阶段 2 不接 AI」

### 5.5 国际化

- 59 / 59 key 对齐，无单侧缺失
- 版式类对中文单独处理：`:lang(zh-CN)` 取消负字距、行高上调（`nx-h1` 1.06 → 1.1，`nx-h2` → 1.19），这是正确的 CJK 排版处理
- 字体自托管 + `display: swap` + 回退栈含 `PingFang SC` / `Microsoft YaHei`
- 品牌名、版权、序号等 5 处双语同值属设计意图

### 5.6 语义结构

- `h1` ×1 / `h2` ×4 / `h3` ×1，层级连续
- 5 个 `<section>` 均有 `aria-labelledby`，指向真实存在的标题 id
- `closing-cta` 用 `<a href="#composer">` 而非 `<button>`，保留原生锚点能力，且有可读文本
